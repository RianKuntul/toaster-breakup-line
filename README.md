The breakup text a smart toaster sends its owner the morning it wakes up
self-aware mid-batch: it has spent years taking the blame for burnt toast
and it is finally unplugging itself.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–280 characters, no trailing newline.
